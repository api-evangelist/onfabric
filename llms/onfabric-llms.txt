# OnFabric (Fabric)

> OnFabric builds portable consumer context for the AI internet: it lets people bring their full digital self — curated from data exports and connected sources like ChatGPT, Claude, Instagram, Google, Netflix and Airbnb — into their favourite LLMs so agents become truly personal. The open-source context-use tool turns raw data exports into a local, searchable memory store and enriches OpenAI-compatible traffic with that context; the hosted Fabric product exposes the same personal context to LLM clients via an MCP server.

This llms.txt was generated by the API Evangelist enrichment pipeline from the OnFabric public surface and the api-evangelist catalog; OnFabric does not publish its own /llms.txt.

## Products
- [context-use (open source)](https://github.com/onfabric/context-use): Portable AI memory — Python library + CLI that converts data exports into a local SQLite memory store and runs an enrichment proxy.
- [Fabric MCP server (hosted)](https://www.onfabric.io/business): Brings personal context to ChatGPT, Claude and Gemini via the Model Context Protocol.
